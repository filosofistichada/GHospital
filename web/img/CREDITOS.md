# Créditos de imágenes y recursos

Todas las ilustraciones de `web/img/*.svg` fueron dibujadas a mano en SVG para este proyecto
(tiburón, ciclón, murallas, jaguar, estrella, el Coste, comida, hamaca, doctor, camillero y picó).
No se usan escudos oficiales de los equipos ni arte del juego Virus!: cada equipo se representa con
sus colores y un ícono propio. El Coste es un personaje caricaturizado, no una persona real.
